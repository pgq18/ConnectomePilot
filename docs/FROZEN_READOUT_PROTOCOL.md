# 先训练脑内连接，再冻结连接训练读出：预定协议

日期：2026-09-16。检验用户提出的策略：从 65,536 步的“PPO 脑内连接＋读出”检查点出发，冻结已学习的脑内连接，继续优化读出，是否优于持续联合训练或从一开始只训练读出。

## 固定设置

- 同一个 MaleCNS 真实连接子图：4,096 个神经元、459,342 条允许连接、1,314 个下降神经元读出；人为设定的感觉输入、简化速率动态及二维机器人动作残差映射沿用前轮。
- 三个来源种子 71、72、73，全部使用 `results/plasticity/main/ppo_edges-<seed>/final.pt`，总步数 65,536。
- 保留来源的脑内连接、actor、critic、固定读出校准及 actor/critic 的 Adam 动量和更新计数。加载原完整模型及优化器后关闭脑内连接梯度，并将其从优化器参数及状态中移除；不重新初始化读出。
- 只训练原有线性动作读出（actor）和价值读出（critic），共 3,960 个参数。旧检查点缺少环境/脑状态/RNG，继续沿用上轮处理：从新回合开始，环境种子为训练种子加 1,000,000，Torch 种子加 2,000,000；地图池仍为 20,000,000–20,999,999。
- 每个种子增加 196,608 步，达到 **262,144 总步数**；三个种子共增加 589,824 步。固定记录 65,536、131,072、262,144 三个节点。
- PPO 设置保持原样：Adam 学习率 0.0003，8 个环境，rollout 128，minibatch 64，4 轮更新，裁剪 0.2，GAE 0.95、折扣 0.99，奖励缩放 0.1，固定高斯标准差 0.4，梯度范数上限 0.5。核心采样与 PPO 更新代码与上一轮完全相同。
- 不按照中间成绩调参、提前停止或挑选模型。训练结束后的固定 262,144 步模型参与主要比较。

## 冻结与续训核验

PyTorch 优化器默认按参数顺序对应保存的状态，因此先按原联合训练的完整参数布局加载，再移除脑内连接，保留读出对应的 Adam 状态，参见 [PyTorch 优化器状态文档](https://docs.pytorch.org/docs/stable/generated/torch.optim.Optimizer.state_dict.html)。关闭梯度的机制参见 [PyTorch 自动求导说明](https://docs.pytorch.org/docs/stable/notes/autograd.html)。运行使用工作站已有 PyTorch，不升级依赖。

每个 rollout 核验脑内连接与来源检查点完全相等且没有梯度。新测试验证冻结不改变初始输出、读出 Adam 状态被保留、后续仅读出变化、保存后重新加载的下一次更新一致。先在真实图上跑种子 71 的 1,024 步流程检查，使用 5,499,800–5,499,807 地图；这些结果不纳入正式成绩。
