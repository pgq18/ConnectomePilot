# 先联合训练，再冻结脑内连接：成功率提高到 80.7%

日期：2026-09-16。按用户提出的方法，从三个 **65,536 步的“PPO 脑内连接＋读出”检查点**出发，保留已学习的连接和读出，冻结脑内连接，仅续训读出至 **262,144 总步数**。三个种子已完成，全部新地图评估和模型核验通过。

**这条分阶段训练路线效果更好：新测试集平均成功率为 80.7%，比全程只训练读出高 21.2 个百分点，比持续联合训练高 44.8 个百分点。三个种子均超过两个长训对照。**

## 主要对照：全部模型使用同一批新地图

测试地图为 5,600,000–5,600,199，共 200 张，前几轮未使用。所有训练结束后统一测试，每种方法三个训练种子。下表为种子间均值 ± 样本标准差，不是置信区间；同一批地图在不同训练种子下重复评估。

|方法|种子 71|种子 72|种子 73|均值 ± 样本标准差|
|---|---:|---:|---:|---:|
|联合训练 65,536 步：续训起点|46.0%|55.5%|63.0%|54.8 ± 8.5%|
|持续联合训练至 262,144 步|50.0%|29.5%|28.0%|35.8 ± 12.3%|
|全程只训练读出至 262,144 步|58.5%|58.5%|61.5%|59.5 ± 1.7%|
|**先联合，再冻结脑内连接，至 262,144 步**|**80.5%**|**84.0%**|**77.5%**|**80.7 ± 3.3%**|

分阶段训练相对“全程只训练读出”的逐种子提升为 **22.0、25.5、16.0 个百分点**；相对各自联合短训起点，提升为 **34.5、28.5、14.5 个百分点**。本轮固定比较最终检查点，没有根据验证集挑选模型。

## 冻结后，果蝇脑承担什么工作

本轮继续使用真实 MaleCNS 的 **4,096 神经元、459,342 条允许连接**子图和 **1,314 个下降神经元读出**。脑内连接已在前 65,536 步联合训练中被调整，之后保持固定。每一步观测仍经过脑内传播，产生神经活动；PPO 只继续调整这些活动到动作、价值的线性读出，共 **3,960 个参数**。

```text
前 65,536 步：观测 → 可学习的脑内连接 → 可学习的读出 → 小车动作残差
之后 196,608 步：观测 → 固定已学脑内连接 → 继续学习读出 → 小车动作残差
```

节点动态、感觉编码、动作映射和奖励沿用前轮。连接来源是真实解剖数据；神经动态与机器人接口为工程建模，当前实验是二维仿真避障。

一种与结果相符的解释是：冻结后，读出可以适应稳定的神经活动，而持续联合训练会同时改变其输入。**本轮直接证明的是该训练顺序在当前设置下的效果，尚未单独验证这一机制，也未搜索最佳冻结时机。**

## 冻结、优化器与数值核验

- 三个最终模型的脑内连接与各自 65,536 步来源检查点**逐字节一致**，最大权重变化为 **0**；每个 rollout 也检查权重未变、梯度为空。
- 图的连接位置、递质符号、感觉映射、神经元读出索引及固定校准统计均保持一致。读出权重确实更新。
- 先按原联合模型的参数布局加载 Adam，再移除脑内连接参数及其状态。保留读出已有的动量与更新计数，计数 **4096 → 16384**，没有重新初始化读出。
- 原采样和 PPO 更新代码与上一轮逐字一致；学习率、奖励、批量、裁剪参数和训练地图池均未改变。完整设置见[预定协议](FROZEN_READOUT_PROTOCOL.md)。
- **43 项测试通过**。新增两项测试覆盖冻结前后预测与读出 Adam 状态保持、后续仅更新读出，以及保存后恢复的下一次更新一致。真实图短流程还检查了 Adam 4096 → 4160。
- 旧检查点缺少环境/脑状态/RNG，因此本次从新回合继续，采用与上一轮相同的新回合种子方案。新检查点保存完整环境、脑状态、读出优化器和 RNG。

### 起点重测的浮点差异

初始验证的 300 个回合，逐地图的成功/碰撞/超时结果与上一轮完全一致；浮点回报未逐位相同。三个种子的平均回报差分别约为 **+0.00019、−0.000002、−0.00932**；最大单回合回报差约 **0.9293**，没有改变该回合的结果类别。原始差异保存在汇总数据中。

当前实现使用 CUDA 上的 `index_add`，且正式实验沿用此前的非全局确定性设置。这种浮点轨迹差异与该运算的非确定性相符，参见 [PyTorch 确定性算法说明](https://docs.pytorch.org/docs/stable/generated/torch.use_deterministic_algorithms.html)。额外在确定性 GPU 运算下核验三个真实来源模型，每个使用同一批 8 个训练环境观测，冻结前后的动作均值、价值、脑状态、读出特征全部完全相同。该检查没有改变正式训练或测试结果。

## 结论

**当前应优先保留“先联合训练 65,536 步，再冻结脑内连接训练读出”作为避障实验基线。** 它在三种子、两批测试地图上均超过全程只训练读出与持续联合训练。后续可检验更长读出训练的上限与不同冻结时机；本轮尚未执行这些扩展。

结果目前属于该真实子图上的二维仿真任务，尚未评估机械臂或硬件迁移。本轮三个模型保存为离线评估结果，网页继续使用此前的控制器。
