# 延长奖励学习预算：预定对照

日期：2026-09-15。问题：从此前 65,536 步继续训练，成功率能否进一步提高？

## 固定条件与预算

- 沿用首轮同一个真实 MaleCNS 子图：4,096 神经元、459,342 条允许连接、1,314 个下降神经元读出。
- 保留 readout、ppo_edges、three_factor 三组，各种子 71、72、73。
- 每个模型从对应 65,536 步最终检查点继续到 **262,144 总步数**，即每个模型新增 **196,608 步**；九组新增合计 **1,769,472 步**。
- 记录 65,536、131,072、262,144 步三个固定节点。不根据成绩提前停止、改学习率或选择检查点；若数值异常则记录失败。
- 图、归一化统计、感觉映射、节点动态、奖励、PPO 超参数、局部学习超参数、批量 8、rollout 128、minibatch 64 全部沿用上一轮。核心更新代码与原训练器一致。

## 续训边界

旧检查点保存了模型参数与 Adam 状态，但没有保存环境、脑状态与随机数状态。因此第一段续训保留模型及优化器，重置环境回合和脑状态。三因素学习保留权重，同时清空旧回合的资格迹。新采样种子为训练种子加 1,000,000，Torch 种子加 2,000,000；仍在原训练地图池 20,000,000–20,999,999 内采样。

这属于断点后的继续学习，不能宣称与从头不中断训练 262,144 步逐位相同。新检查点补齐了环境状态、每环境随机数生成器、当前观测、脑状态、回合起点标记、Torch CPU/GPU 随机数状态、优化器和资格迹，并以临时文件写完后替换。

模型与优化器一起恢复的做法参照 [PyTorch 检查点文档](https://docs.pytorch.org/tutorials/beginner/saving_loading_models.html)。实际训练沿用工作站已有 PyTorch 2.11.0+cu128，而非更换为文档页面的最新版。

## 评估与结论

- **验证地图**：5,400,000–5,400,099，共 100 张。三个固定训练节点评估正常传感器条件，用来描述趋势，不用于挑选模型。
- **新最终测试地图**：5,500,000–5,500,199，共 200 张。所有九组训练结束后，统一重新评估原 65,536 步模型与最终 262,144 步模型；这是续训前后的主要比较。
- **原测试地图复测**：5,300,000–5,300,099。最终模型评估正常传感器、0.05 米距离噪声、100 毫秒延迟，与上一轮保存的结果对照；作为次要结果，不替代新测试集。
- 评估固定模型、确定性动作；每组报告三种子的成功率均值/样本标准差、逐种子变化、成功/碰撞/超时数、任务回报、耗时与峰值显存。
- 保留所有固定节点模型和逐地图结果。只训练读出作为对照，以区分训练预算的普遍作用与训练脑内权重的额外收益。局部学习保留用于检验首轮停滞能否随更多训练改善。
- 新测试集仅在训练结束后读取。不重用它进行本轮任何超参数选择。
