# 群体读出 PPO：首轮试验协议

本轮问题：在相同导航任务、原始传感信息、动作接口与训练步数下，真实 MaleCNS
连接上的冻结动态，能否提供比普通网络和打乱连接更有用的避障特征？
这是一轮探索性试验，不预设真实连接优于人工网络。

## 借鉴与实现

- [fly-craftax](https://github.com/liuzihe02/fly-craftax/blob/main/flycraftax/ppo.py)：
  冻结脑内连接，训练下行神经元群体读出。
- [fly.ai](https://github.com/alextitonis/fly.ai/blob/main/flybrain/reservoir.py)：
  保留神经元活动的衰减历史。
- [FlyDoom](https://github.com/eganeganegan/flydoom)：稀疏循环计算与连接扰乱对照。
- PPO 使用标准 clipped objective、GAE、梯度裁剪和 KL 停止；可参考
  [CleanRL 的连续动作和循环 PPO](https://github.com/vwxyzjn/cleanrl)。
  本项目实现共享的 GRU/MLP/群体读出训练器，不引入额外训练包。

本轮不进行脑内连接学习，也未引入 FlyGM 的模仿学习阶段。

## 数据与编码

- 所有 166,700 个已保留神经元、25,582,938 条连接参与稀疏 LIF 传播。
- 权重仍为连接计数、递质预测符号和输入绝对权重归一化的工程变换。
- 9 路距离和 9 路有符号接近速度分别编码，不提前压缩成左右两值。
- 使用 LC4、LPLC2、LC11、LC9、LC15、LC16、LC17、LC21 中有左右侧标注的神经元。
  左右半球限制方位；同侧按 body ID 排序划分不同通道。此划分是可重复的工程映射，
  不是推断出的生理感受野或视网膜模型。
- 读取全部 1,314 个 descending_neuron，分别用 50ms / 200ms 衰减轨迹，得到 2,628 维。
- 目标方向正弦/余弦、目标距离、当前线速度/角速度这 5 维作为所有策略的直接上下文。
  果蝇策略没有距离或接近速度直达读出层的旁路。
- 动态 dt=20ms，每动作 5 步；时间常数 100ms、递归增益 3、基础驱动 0.14、
  输入增益 0.9、随机驱动 1.2Hz×0.22。输入诊断另关闭噪声以识别刺激的直接影响。

## 比较条件

| 名称 | 策略输入与计算 | 隐层规模 |
|---|---|---|
| mlp | 23 维观测 → 两层 MLP | 576 |
| gru | 23 维观测 → 投影 → GRU | 240 |
| fly | 冻结真实整脑 → 2,633 维输入 → 两层读出 MLP | 128 |
| shuffled | 冻结扰乱整脑 → 相同群体读出 | 128 |

四种策略训练参数约 35 万，精确值写入每次 run.json；不把冻结的连接数当作训练参数。
目标重排使用固定种子 20260915 对权重矩阵的行进行置换。保留连接总数、权重值、
各源节点出度和入度分布，但不保留每个具名神经元的入度，不称为度保持边交换。

同一基础目标控制器、残差限幅和最终动作限幅。策略输出 tanh 高斯的连续残差，
训练和更新均计算同一动作分布概率。奖励沿用导航环境，加 0.005×归一化残差平方惩罚。
600 步超时定义为有限时域任务结束，不向后续重置回合引导价值。

## 训练和评估

开发验证：种子 7，每组 2,048 步，8 个开发场景 1001000–1001007；不计入结果主表。

首轮主试验：

- 训练种子 11 / 22 / 33，每组 100,352 个环境步；32 环境、64 步 rollout。
- 初始学习率 3e-4，4 epochs，4 minibatches；gamma=.99、GAE lambda=.95、
  PPO clip=.2、熵系数=.001、价值系数=.5、梯度范数上限=.5、KL>.03 停止当前更新。
- GRU 按连续 32 步序列更新，保留初始隐状态，并在回合边界清零。它确实通过时间训练，
  不把 GRU 当成无状态的逐帧层。
- 在线观测归一化；更新时使用采样时保存的归一化观测，评估时冻结统计量。
- 训练场景从 [0,1,000,000) 抽样。测试场景固定 3000000–3000099。
- 每个条件均报告全部三个种子；选择最后一个训练检查点，不按测试分数挑模型。
- clean、noise（距离高斯噪声标准差 0.05m）、delay（距离延迟 1 个控制步）
  使用相同测试场景，噪声按场景编号与时间步确定。
- 机制消融使用预先指定的种子 11：真实与扰乱网络分别关闭输入、静默脑活动读出。
  该消融不重新训练，不用于代替主试验。

记录成功/碰撞/超时、任务回报、平均每步角速度动作变化、训练吞吐与峰值显存。
同一批测试地图在种子间重复，不能把三个种子的 300 次评估当成 300 个独立地图。

## 资源和解释

优先使用空闲的 GPU 1；GPU 0 在启动检查时已有其他高负载任务。
基准先测 1/8/32 环境，计时前后同步实际使用的 GPU。
GPU CSR 与 CPU SciPy 稀疏乘法做数值比对；GPU 浮点归约不要求所有脉冲轨迹逐位相同。

若有响应却没有控制提升，应分析读出、编码和时间尺度；若真实与扰乱网络接近，
当前证据不足以支持连接拓扑优势。神经元有响应、权重更新或训练回报提高都不单独
构成可靠避障或生物真实性证据。结果只适用于当前二维运动学任务。
