# 同一果蝇连接子图上的三种学习规则

日期：2026-09-15。正式运行前锁定；本轮是方法可行性试验，不是生物真实性或优于普通 PPO 的证明。

## 问题与依据

固定真实连接位置后，奖励能否通过 PPO 梯度或局部可塑性改变脑内连接强度，并改善现有连续残差避障任务？对照组只让 PPO 学习读出层。

算法参考：[FlyDoom](https://github.com/eganeganegan/flydoom/tree/b047fabffb62e10268de2fc1f12c765b8b019c0b)，固定提交 `b047fabffb62e10268de2fc1f12c765b8b019c0b`。本项目独立适配其连续神经元状态、固定拓扑 PPO、三因素更新公式。没有运行原版 Doom，也没有直接复现上游成绩。

参考文件：`models/connectome_network.py`、`models/graph_policy.py`、`training/ppo.py`、`training/three_factor.py`（均位于上游 `src/flydoom/`）。上游布尔索引后的原位限幅不会写回原张量；本实现显式投影回权重张量，并有测试覆盖。

## 共享结构

- 数据：已有 MaleCNS 真实连接数据，原图 166,700 神经元、25,582,938 条边。
- 子图：4,096 神经元、459,342 条真实边，保留全部 1,487 个工程视觉输入神经元和全部 1,314 个下降神经元。
- 选择：输入到输出的多源 BFS 路径并集需要 3,012 节点，再按两跳输入输出路径的绝对权重乘积补足 4,096 节点。所有下降神经元在子图内仍可由输入到达。取诱导子图，保存原始 body ID 和索引。
- 初始连接：沿用带递质符号假设的突触计数权重，在子图内按每个目标神经元的输入绝对权重和重新归一化。此处不同于 FlyDoom 的 `log1p(count)` 初始化。
- 每神经元一个连续状态，`tanh(0.5 * state + recurrent + input)`，每个动作更新五次；保留跨动作状态，回合结束清零。
- 固定输入：9 路距离和 9 路接近速度映射到现有视觉细胞，输入增益 0.9；这不是还原的果蝇视网膜。输入映射、零偏置、泄漏系数全部不训练。
- 读出：1,314 个下降神经元状态先用训练地图的 4,096 帧随机动作轨迹校准每个神经元均值和标准差，标准差下限 0.001，截断至 ±5，再除以 `sqrt(1314)`。校准后冻结，三组共用同一份。
- 另外向读出直接提供五个目标/运动上下文量，不直接提供距离/接近速度。
- 策略和价值函数都是线性读出。动作是两维固定标准差 0.4 的高斯变量经 tanh 转换，接原有线速度/角速度残差接口。动作、奖励和基础导航控制器三组完全相同。

## 三组

|组|脑内连接强度|策略/价值读出|更新方式|
|---|---|---|---|
|readout|固定|学习|PPO|
|ppo_edges|学习，位置及符号固定|学习|PPO|
|three_factor|学习，位置及符号固定|学习|局部资格迹 × TD 预测误差，无反向传播|

PPO：Adam 0.0003，折扣 0.99，GAE 0.95，裁剪 0.2，价值损失系数 0.5，梯度范数上限 0.5，每批数据优化四轮。沿用上游逐动作重放思路，以采样时保存的脑状态为起点，对五个内部更新步骤求导，不跨环境动作做长序列反向传播。探索方差固定，其未压缩高斯熵为常数。

局部学习：`delta = clip(0.1*r + 0.99*(1-done)*Vnext - V, -5,5)`；边资格迹为 `clip(0.95*e + pre*(post - mean(post over edges)), -5,5)`。每条边的增量为 `0.0001 * mean(delta * e over environments)`。有每步 0.000001 的回归初始权重项；更新后投影，保持原有符号、幅度不超过 1。

连续动作使用高斯策略的解析得分 `(latent - mean)/std²` 替代上游离散动作的 one-hot 减概率。策略资格迹衰减 0.95，学习率 0.002；价值读出 TD 学习率 0.005；读出参数限制 ±3。每个并行环境有独立资格迹，完成回合后清零自己的迹，保留已经学到的权重。

为比较连接学习，本轮关闭上游的神经元偏置稳态更新及多巴胺细胞活动注入。TD 信号作为全局标量调制所有子图边，未实现 KC→MBON 特异性、多巴胺分区、脉冲时序可塑性。这是奖励调制的工程模型。

## 预算与证据

- 硬件：RTX 5090 工作站 的物理 GPU 1，项目 Conda；通过 `CUDA_VISIBLE_DEVICES=1` 隔离。GPU 0 保留给已有任务。
- 首轮预算：每组每种子 65,536 环境步；种子 71、72、73；8 个并行环境，128 步 rollout，PPO minibatch 64。短流程验证用种子 70、2,048 步、验证地图 5,200,000–5,200,007。
- 训练地图：20,000,000–20,999,999。三组同种子共用相同的地图抽样序列；由于策略导致回合长度不同，有限预算内实际访问的地图数与轨迹不保证相同。
- 无模仿学习、无教师示范、无 DAgger。三组同种子初始状态逐张量哈希必须相同。
- 最终测试：5,300,000–5,300,099，与以前试验及本轮训练/校准/短测试地图分离。固定步数结束后只评估最终模型，不根据测试成绩选检查点。
- 初始模型：在同一百张地图评估 clean。最终模型：clean、距离噪声标准差 0.05 米、传感器延迟一帧（100 毫秒）。评估中冻结一切学习，使用确定性动作。
- 主指标：三种子的成功率均值和种子间样本标准差；报告碰撞/超时数、任务回报、训练秒数及 PyTorch 张量峰值显存。三种子不足以作强统计结论。
- 机制检查：权重变化数量/幅度、符号违规数；种子 71 的两种内部学习模型保留最终读出、恢复初始脑内权重后再评估 clean，判断行为是否依赖更新后的边。这个恢复试验不是重新训练的消融，也不代表边变化单独有因果收益。
- 测试覆盖：投影写回、真实边梯度、回合状态重置、高斯局部策略得分与自动微分一致、奖励调制生效、每环境资格迹重置、训练地图范围与重置观测。
- 所有模型、逐回合结果、超参数、校准统计、源文件哈希和实测资源记录保存在 `results/plasticity/`，不覆盖此前试验。

## 解释边界

这三组只能比较当前子图、输入、动力学和训练预算下的学习行为。不能证明真实果蝇的学习机制被复现，也不能证明果蝇拓扑优于同规模随机图或普通网络；这需要另外的拓扑对照、预算搜索与更多种子。4096 节点子图和之前全脑模型不同，因此本轮成绩不与前两轮跨试验直接归因比较。
