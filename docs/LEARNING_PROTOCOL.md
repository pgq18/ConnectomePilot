# 可训练果蝇动态＋示范学习＋PPO：执行协议

目标：检验学会感觉编码与神经元动态、再用示范初始化，是否能改善上一轮冻结 LIF 的控制失败。
本轮是一个独立的工程控制模型；不把连续状态动态称为原始果蝇神经元生理模拟。

## 数据与老师

- 同一二维 clutter 任务、原始 23 维观测、基础目标控制器和连续残差限幅。
- 几何老师：可见图最短路径、圆形障碍膨胀、转向跟踪与近障减速。
  老师知道障碍坐标；学生只看距离、接近速度、目标和运动状态。
- 老师开发地图 4100000–4100049；示范地图 10000000–10000127。
  示范执行动作有固定种子短时扰动，但标签来自该状态下的老师动作。
- 每组 DAgger 使用地图 10100000–10100031，由学生执行、老师标注，记录全部失败回合。
  每组获得同样 32 回合的标注预算，访问到的状态可以不同。
- PPO 训练地图从 [10000000,11000000) 抽样。
- 验证地图 4200000–4200031。正式测试地图 4300000–4300099。
- 开发流程试跑种子 7、4 张地图 4400000–4400003；不计入正式结果。

## 感觉诊断

在原始冻结 LIF 真实图和扰乱图上跑同一批示范，取每三帧的下行神经元快慢活动轨迹，
训练 ridge 线性解码器预测 9 路距离和 9 路接近速度。固定正则系数 10；
按完整地图分离训练和验证，禁止随机拆帧。报告 R²、物理单位 RMSE、最近障碍方位准确率。
另有仅上下文和原始传感器的解码对照。诊断分布是老师轨迹，不能代表任意状态的信息容量。

## 可微网络

- 完整保留 166,700 个节点和 25,582,938 条测得的有向边，沿用处理后的带符号归一化权重。
- 每节点一个连续状态，每控制周期 5 次更新：
  `h_next = retention*h + (1-retention)*tanh(gain*(W h) + bias + sensory_drive)`。
- 每节点 gain、bias、retention 可训练；gain=3×sigmoid 初始 1，retention=.05+.9×sigmoid 初始 .5。
- 18 维感觉经过 64 隐单元编码器投射到 1,487 个视觉输入节点；编码器可训练。
- 读取全部 1,314 个下行节点，经无仿射 LayerNorm 后与 5 维目标/运动上下文连接，
  由 128/128 读出输出两个动作残差。距离/接近速度没有直接到动作头的旁路。
- 连接权重固定，以实际数组 SHA256 验证；固定稀疏矩阵的反向传播使用转置 CSR。
  小图密集计算对照验证梯度，完整图检查梯度非零和显存。
- 扰乱图沿用固定种子 20260915 的行置换；不是逐节点保持入度的边交换。
- MLP 隐层 864/864；GRU 隐层 352。精确训练参数写入 run.json，约与果蝇模型相当。
- 四组共享独立的 23→128→128→1 价值网络。价值网络看原始观测，动作网络遵循各组接口。
- 观测归一化使用同一示范集的固定均值、标准差（下限 .1）；不随 PPO 更新。

## 训练预算和比较

正式种子 61、62、63，每种子 mlp / gru / fly / shuffled 四组，在 GPU 1 串行运行。

1. 256 次模仿更新，每次 8 段×16 帧，另 8 帧无梯度预热；Adam lr=.001。
   模仿损失为归一化残差 MSE，帧权重 `1+2*abs(老师角速度残差)`，所有组相同。
2. 32 回合学生状态收集，加入原始示范后再做 128 次相同模仿更新。
3. 从最终模仿检查点出发，PPO 32,768 环境步；8 环境、32 步 rollout、16 步连续序列。
   Adam lr=.0001、2 epochs、4 minibatches、clip=.2、gamma=.99、GAE=.95、
   熵系数 .001、价值系数 .5、梯度上限 .5、当前 epoch 平均 KL>.03 则停止当前更新。
   熵采用底层高斯熵近似。PPO 沿用原环境奖励及 .005×归一化残差平方惩罚。
4. 固定评估最终模仿和最终 PPO 两个阶段，不根据测试成绩选择检查点或调参。
   clean / noise（距离 σ=.05m）/ delay（距离延迟 100ms）各 100 张测试图。
   所有组和所有训练种子共用同一批地图，报告种子标准差，不当作 300 张独立地图。

补充复查在主试验开始后、查看果蝇正式测试结果之前固定为种子 61：对真实/扰乱图分别
关闭感觉驱动、静默神经读出、恢复初始神经元动态参数（保留训练后的编码器和读出）。
这是单种子分布干预，不能独立证明生物机制。轨迹示例固定为测试地图的前 3 张，
不按成功与否挑选。另将旧版冻结 LIF 的三个检查点在这批新地图上重新评估，
便于比较两套完整方案；两套方案的示范与训练预算不同，不用于单独归因。

本轮暂不训练全部边权，不引入真实机器人。借鉴
[FLYNN](https://arxiv.org/html/2607.00025v1) 的连续动态与 DAgger，及
[FlyGM](https://arxiv.org/html/2602.17997v3) 的固定连接、可训练节点计算和模仿后 PPO。
实现不是上述论文的完整复现。老师近障减速的工程依据可参考
[Nav2 路径跟踪说明](https://docs.nav2.org/rolling/configuration_and_development/configuration_guide/controller_plugins/configuring_regulated_pp/)。
