# 从避障小游戏到机器人残差控制

## 已实现的阶段

目前已完成二维避障、整脑群体读出 PPO，以及真实子图“联合学习连接和读出 → 冻结连接继续学习读出”的训练链。最新模型使用 4,096 个神经元和 1,314 个下行输出，详见[功能实现](ARCHITECTURE.md)与[4M 实验](STAGED_4M_TRIAL.md)。下文的双输出 LIF 描述针对早期网页控制器；后续机械臂与硬件接口仍是规划。

## 当前接口

每个控制周期明确分开：

1. `observation`：传感器、目标相对方向、上一周期速度。
2. `base_action`：已有控制器给出的动作。
3. `residual_action`：果蝇网络读出或策略网络给出的修正。
4. `final_action = bound(base_action + bounded_residual)`。
5. `reward / terminated / truncated / info`：Gymnasium 训练边界。

当前演示中动作是 `[线速度 m/s, 角速度 rad/s]`，控制步长为 0.1 秒。
早期 LIF 网络每个控制周期运行五次 20 ms 神经更新。运行慢时模拟时间变慢，
不会假装神经计算达到了实时。模型采用固定连接的 LIF 单元。

## 当前能说明什么

二维场景可以验证输入、循环状态、动作合成和评估流程。它不能验证真实
机器人动力学，也不能证明生物连接图优于普通网络。测量连接结构、推断的
递质符号、人工设置的神经动力学和人工动作映射，应分别记录。

当前输入把距离近似为“接近威胁”的强度，直接刺激 LC4/LPLC2；不模拟视网膜。
DNp01 左右输出被人工映射为减速和转向残差。DNp01 在生物学中与逃逸有关，
这里的转向含义是工程接口。现有版本没有在线学习。

## 第一阶段：移动机器人

- 保持基础导航控制器，先用低维距离观测作为独立传感基线。
- 使用冻结的果蝇网络，将其活动作为残差策略的输入，训练小型输出网络。
- 对照：基础控制；规则避障；纯传感 MLP-PPO；冻结果蝇网络加同规模读出。
- 固定场景分布、训练交互次数和评估种子，记录成功率、碰撞、停滞、路径长度、
  最小间距、计算延迟。真实连接与打乱连接需匹配图规模和权重分布。
- 第一版里传感 PPO 和果蝇 PPO 的输入信息不同；不能仅比较分数就把差异归因于连接结构。
  研究实验应进一步匹配信息、参数预算和时序状态。

`flylab/gym_env.py` 提供当前环境；`scripts/train_ppo.py` 是可选训练入口。
`features=fly` 时只训练残差输出策略，连接权重冻结，观测包含两个神经输出
和目标/机器人状态，不含距离传感器旁路。

已在本机完成两组各 8,192 步的首轮 PPO 试跑，训练资源和独立评估结果见
[PPO_TRIAL.md](PPO_TRIAL.md)。短训后的果蝇 PPO 未超过传感器策略或手工映射，
后续需要区分训练量、神经读出信息与奖励设计的影响。

## 第二阶段：机械臂动作残差

保留同样的数据流，但替换观测与动作定义：

- 观测：关节状态、末端与目标误差、接触/力信息、基础策略动作。
- 基础策略：已有抓取策略、轨迹跟踪器或阻抗控制器。
- 第一种残差空间：末端位置与姿态增量，或关节目标增量。
- 后续再考虑力矩残差；它对模型精度、时延和接触稳定性要求更高。
- 以小幅残差开始，在仿真中验证动作限幅、平滑性、接触和终止逻辑。

果蝇网络不能直接理解机械臂的关节或力矩。需要新编码器和输出映射，
更可能首先验证的是“生物连接结构作为循环动态特征是否有帮助”。
目前尚未实现从移动避障映射到机械臂的迁移。

## 第三阶段：训练连接本身

该方向已在真实连接子图的简化连续状态模型中实现 PPO 与局部规则，并完成分阶段冻结试验；见[连接学习报告](PLASTICITY_TRIAL.md)和[训练指南](TRAINING.md)。以下是继续扩大到其他模型和任务时的设计要点。

在冻结网络加读出仍不足时，再逐步解冻连接：先训练少量通路/增益，之后
考虑受连接掩码限制的内部权重。保持兴奋/抑制符号需要显式约束；修改
符号或添加连接应作为单独实验。脉冲神经网络的离散阈值需要代理梯度
或其他学习规则，不等同于给普通 PyTorch 权重加一个优化器。
